# KinoNoxLite — учебное кино-приложение (PB7)

> Слой: **продукт (учебный)**. Статическое приложение для курса PB7 «Programmu testēšana»: на нём студенты тренируют тест-дизайн и заведение дефектов.

## Что это

Кино-приложение на чистом HTML/JS: каталог фильмов, сеансы, схема зала, бронирование с таймером, семь типов билетов и скидки, оплата, профиль с регистрацией. Работает локально, без .NET, без БД, без интернета — данные в `localStorage`.

## Правила

1. Приложение — **учебный стенд**: ошибки в нём умышленны там, где они заведены карточками панели. Не «починивать» на глаз — сверять с дефектами проекта `kn`.
2. Версия и `TODO.md` обновляются вместе с правкой кода; версия также регистрируется в каталоге панели.
3. Данные только в `localStorage`; никаких внешних API и секретов.
4. Персональные данные студентов в репозиторий не попадают (студенческие работы — в материалах курса, не здесь).
